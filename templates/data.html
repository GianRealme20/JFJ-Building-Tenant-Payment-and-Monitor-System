Import directly from a Google Sheet link

No Google Cloud setup needed. Paste a sheet link and the rows will be appended.

How to share it: In Google Sheets choose Share and set Anyone with the link → Viewer. Private sheets can also be imported by publishing them with File → Share → Publish to web → CSV and pasting that published link. The first row must contain column headers.

How to set up direct Google Sheets sync
  1. Go to console.cloud.google.com and create (or select) a project.
  2. Enable the Google Sheets API for that project.
  3. Create a Service Account, then create and download a JSON key.
  4. Add the key path to your .env file:
    GOOGLE_SERVICE_ACCOUNT_FILE = C:\path\to\service-account.json
  5. Open the JSON file and copy the client_email address.
  6. In Google Sheets, click Share and add that email as an Editor.
  7. Restart the Flask server so the new `.env` value is loaded.
